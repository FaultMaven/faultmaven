# Archive

Historical and internal documentation.

> **Note**: This folder contains deprecated, superseded, or internal-only documentation.
> These files are preserved for historical context but should not be used for current development.

## Sections

| Section | Description |
|---------|-------------|
| [working](./working/) | Work-in-progress development documents |
| [reports](./reports/) | Internal code reviews and reports |
| [deprecated](./deprecated/) | Superseded documentation |

## Why Archive?

Documents are archived when they:

- Have been superseded by newer documentation
- Were created for a specific development phase
- Are internal reports not intended for end users
- Contain historical context that may be useful later
