# Architecture Decision Records (ADRs)

Records of significant architecture decisions with their context, rationale, and consequences.

## Records

- **[ADR-001: Monolith Evolution Strategy](./adr-001-monolith-evolution-strategy.md)** — Decision to evolve from `FaultMaven-Mono` toward the current modular monolith

## Format

Each ADR follows:

1. **Title**: Brief noun phrase
2. **Status**: Proposed | Accepted | Deprecated | Superseded
3. **Context**: What issue are we addressing?
4. **Decision**: What are we doing?
5. **Consequences**: What becomes easier or harder?
