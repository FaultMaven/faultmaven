# Knowledge Base and AI

Documentation for FaultMaven's knowledge management, vector search, and AI agent intelligence systems.

## Documents

- **[Knowledge Base Architecture](./knowledge-base-architecture.md)** - 3-tier KB system (Global, Team, Personal), storage and retrieval architecture, KB-neutral tool design
- **[Runbook Content Architecture](./runbook-content-architecture.md)** - Runbook template, taxonomy, quality gates, lifecycle governance

## Purpose

This section covers how FaultMaven builds and maintains its knowledge base, performs semantic search using vector embeddings, implements RAG (Retrieval-Augmented Generation), and uses specialized QA tools to answer user questions.

## Key Technologies

- **Vector Database**: ChromaDB for semantic search
- **Embeddings**: BGE-M3 for generating vector embeddings
- **RAG**: Retrieval-Augmented Generation for knowledge-grounded responses
